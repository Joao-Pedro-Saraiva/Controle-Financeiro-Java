# 💰 Controle-Financeiro-Java

Aplicação desktop desenvolvida em Java com JavaFX para gerenciamento de receitas e despesas pessoais. O projeto tem como objetivo praticar conceitos de programação orientada a objetos, desenvolvimento de interfaces gráficas e integração com banco de dados.

## 📌 Funcionalidades
- Cadastro de transações financeiras.
- Listagem de receitas e despesas.
- Consulta do saldo financeiro.
- Edição de transações.
- Exclusão de transações.

## 🛠️ Tecnologias utilizadas
- Java — linguagem de programação.
- JavaFX — desenvolvimento da interface gráfica.
- Maven — gerenciamento de dependências e configuração do projeto.
- JDBC — comunicação com o banco de dados.
- MySQL — armazenamento das transações.
- CSS — estilização da interface.

## 🎯 Objetivo do Projeto
Este projeto foi desenvolvido com foco no aprendizado prático e no aprofundamento dos meus conhecimentos em Java.

Durante o desenvolvimento, optei por não utilizar agentes de programação baseados em IA, como Claude Code ou ferramentas semelhantes, para escrever ou implementar o código. O objetivo foi enfrentar os desafios do desenvolvimento de forma independente, exercitando a resolução de problemas, o raciocínio lógico e a capacidade de tomar decisões técnicas.

Mais do que construir uma aplicação funcional, este projeto representa uma etapa da minha evolução como desenvolvedor, colocando em prática conceitos de orientação a objetos, JavaFX, JDBC, MySQL e organização de código.
